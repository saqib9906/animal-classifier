# Animal image classification using transfer learning

 Animal Image Classification with Transfer Learning
This project is an image classification system that identifies animals in images using deep learning and transfer learning with MobileNetV2.

🚀 Features
Classifies 15 animal classes: Bear, Bird, Cat, Cow, Deer, Dog, Dolphin, Elephant, Giraffe, Horse, Kangaroo, Lion, Panda, Tiger, Zebra

**Uses TensorFlow and Keras**

Transfer learning with pretrained weights from ImageNet (uses less computational power).

Includes data augmentation for better generalization

Model built using Sequential API

Trained on images of size 224x224x3

📁 Dataset
The dataset contains 15 folders, each representing a class.

Each image is labeled based on the folder name.

📦 Tech Stack
Python

TensorFlow / Keras

MobileNetV2 (Transfer Learning)

Google Colab / Jupyter Notebook/ pycharm
